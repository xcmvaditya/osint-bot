## 📌 Overview

**Genius Hacker OSINT Bot** is a powerful Telegram bot for phone number intelligence. It performs OSINT (Open Source Intelligence) lookups to gather information associated with a phone number. The bot includes a unique **Clone Feature** that allows anyone to create their own instance.

---

## ✨ Features

- ✅ **Phone Number Lookup** – Get detailed information about any 10-digit number.
- ✅ **Telegram Channel Verification** – Secure access for community members.
- ✅ **Clone Feature** – Generate a complete bot ZIP file with your own token using `/clone`.
- ✅ **Auto-Save Results** – All lookup data is saved as JSON files.
- ✅ **24/7 Hosting Ready** – Optimized for deployment on platforms like KataBump, Render, or Railway.
- ✅ **Simple Deployment** – Just `npm install` and `npm start`.

## 🚀 Quick Installation

### For Users (Clone & Run)

```bash
# 1. Clone the repository
git clone https://github.com/xcmvaditya/osint-bot.git
cd osint-bot

# 2. Install dependencies
npm install

# 3. Create .env file with your token (or use default)
# BOT_TOKEN=YOUR_BOT_TOKEN_HERE

# 4. Start the bot
npm start
